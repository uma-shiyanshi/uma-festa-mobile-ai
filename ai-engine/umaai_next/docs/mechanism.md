# 通用育成机制与引擎实现口径

> 本文档描述 `umaai-next` 引擎关注的**剧本通用育成机制**与**引擎实现口径**（数据约定、模拟简化、未接线通用项）。
> 术语定义见 [`../GLOSSARY.md`](../GLOSSARY.md)，Crate 拓扑与模块落点见 [`../ARCHITECTURE.md`](../ARCHITECTURE.md)，支援卡固有效果见 [`support_card_unique_effect.md`](support_card_unique_effect.md)。
> 剧本专属机制（剧本资源、特训、专属事件/结局等）由独立剧本仓自持，不进本仓。

---

## 1. 回合、阶段与年份

- **总回合数**：标准育成共 `0–77` 共 78 回合（0-based，游戏显示 1–78）；部分剧本总回合数更少，由具体 `Game` 覆写 `max_turn()`。
- **阶段投影**：引擎契约只投影 `StageId`（见 [ADR-0002](adr/已采纳/0002-已采纳-阶段单向投影.md)）；无剧本基础局 `BasicGame` 使用私有阶段机 `BasicStage`（`Begin → Distribute → StoryShop(留空) → Train → AfterTrain → End(留空)`），主循环为 `run_stage(trainer, rng) → while next() { run_stage }`。
- **特殊回合区间**：

| 阶段 | 回合区间 | 特征 | 判据 |
|---|---|---|---|
| 出道赛前 | `0–10` | 不可比赛，仅训练 / 休息 / 外出 / 事件 | `turn < 11` |
| 出道赛 | `11` | 固定生涯比赛（唯一动作） | 生涯比赛表 |
| 常规育成 | `12–71` | 所有常规动作 + 生涯比赛 + 自选比赛（`13–71`） | 生涯比赛表 / `12 ≤ turn ≤ 71` |
| 夏合宿 | `36–39` / `60–63` | 训练等级取基础值表末级（内置表为 5，训练成功仍累加计数）、不可出行与治病、休息固定体力 `+40` 干劲 `+1`、无随机事件 | 回合区间 |
| URA 回合 | `72–77` | `73 / 75 / 77` 固定决赛；`72 / 74 / 76` 可训练 / 休息 / 普通外出（生病时可治病），不可自选比赛 | 生涯比赛表 / URA 回合 |

- **学年边界**：第 1 年 `0–23`、第 2 年 `24–47`、第 3 年 `48–71`、URA `72–77`。年度结算多在年末回合（`23 / 47 / 71`），不可用「当前年份 − 1」现推上一年。

## 2. 开局与卡组

- **卡组校验**：`BaseGame::new` 支持可变长度卡组，按 `cardId` 判重（同卡不同突破档亦算重复，直接报错）；允许携带多张友人/团队卡，仅取最后一张作为剧本友人。
- **人头布局契约**：`persons[0..deck.len()]` 与 `deck` 逐槽同序，非卡人头（理事长/记者/NPC 等）只在尾部 `add_person` 追加；非卡定位一律走 `person_index_of_type` / `person_index_of_card`，数据表不得写死 `person_index`。
- **开局初始化**：累加各卡初始属性提升与比赛加成；初始体力 `100 / 100`、干劲 `3`（普通）、Hint 折扣总级数 `21`、已学技能分 `510`。
- **构造顺序铁律**：五维上限必须先设剧本基值上限，再累加开局继承上限，不得整体覆写。
- **帧还原分层**：帧 `personDistribution` 中的人员级字段（`isHint` 等红点、非卡人头羁绊）由剧本仓在自身还原层按 `frame_persons` 写回，引擎 `to_base_game` 只回写支援卡 `friendship`；超出引擎默认人头数的下标只做「越界跳过 + 诊断」，不替剧本建人头。

## 3. 训练

- **基础训练等级**：`floor(该训练累计成功次数 / 4) + 1`，上限取训练基础值表实际行数；夏合宿期间直接取表末级（内置表为 5），训练成功仍累加次数。
- **人头分配（`Distribute`）**：
  - 顺序：理事长 → 记者 → 剧本友人 → 团队卡 → 支援卡 → NPC（默认友人 `turn ≥ 2`、记者 `turn ≥ 13` 可出现）。
  - 出现判定：`p = 不在权重 / (500 + 不在权重)`（支援卡 `50`、友人/团队 `100`、理事长/记者固定 `200`、NPC 必出现；出场率提升降低不在权重）。
  - 训练位权重：`[100; 5]` 并在得意位加 `得意率`；每位置常规上限 5 人，友人/团队/理事长/记者优先分散。
- **Hint 分配与触发**：仅支援卡判定（`p = 基础 Hint 率 × (1 + 加成/100)`）；默认在同训练位带叹号人头中随机选 1 个触发（`25%` 加属性、`75%` 加 Hint 等级，两条分支均羁绊 `+5`；支援卡增量 `1 + 卡面 Hint 等级`，单次按 `1 + hint_count_bonus` 触发多次，单卡上限 `60`，满额后转加属性）。
- **训练值公式**：
  - `status_pt[i] = floor((basic[i] + 副属性加成[i]) × (1 + 0.01×友情) × (1 + 0.01×basic_motivation×(1 + 0.01×干劲加成)) × (1 + 0.01×训练效果) × (1 + 0.05×人数) × (1 + 0.01×成长率[i]))`，其中 `basic_motivation = (干劲 − 3) × 10`；人数含 NPC 与分身、排除理事长/记者。
  - 体力消耗为负时乘 `(1 − 体力消耗降低% / 100)`；智训练有闪彩时额外加「智训练回体」词条。
  - 友情加成仅闪彩（支援卡在得意位且羁绊 `≥ 80`，或团队卡在 `has_group_buff()` 生效期）时生效，多张累乘 `(100+a)(100+b)/100 − 100`。
- **失败率拟合**：`体力 < x0` 时 `f = min((100 − 体力) × (x0 − 体力) / 40, 99)`，再乘 `(100 − 失败率下降) / 100` 加 `bias`（擅长 `−2` / 不擅长 `+2`），夹至 `[0, 100]`。
- **训练后羁绊与事件**：训练后支援卡羁绊 `+7`、理事长/记者 `+5`（爱娇全渠道正向获取额外 `+2`，上限 `100`）；依次触发 Hint 事件、非夏合宿加练事件（理事长 `+5`）、友人首次登场/点击事件、理事长/记者点击事件。
- **数值与显示口径**：引擎默认训练公式直接计算总增量（不拆上下层、无单次 100 上限）；五维属性 `> 1200` 仅游戏显示时超过部分减半，AI 内部全程按原始值计算。

## 4. 比赛、休息与外出

- **生涯比赛**：turn `11–71` 由马娘表决定，加上 URA `73 / 75 / 77`（默认全胜，不模拟未胜利赛）。
- **自选比赛**：`13–71` 回合按比赛等级表判定（`can_self_race`；`BasicGame::list_actions` 历史口径自 `14` 起；`0 = 无比赛`、`1 = G1 … 4 = OP`，`0` 或决赛期不提供自选比赛）；区间结束未达标则育成终止。
- **比赛加成**：仅乘算比赛事件的五维与 PT（`floor(val × (100 + race_bonus) / 100)`，含 `extra_status.random`），不影响体力/干劲。
- **休息 / 外出 / 治病**：非夏合宿休息按默认权重 `18 / 57 / 25` 抽体力 `+30 / +50 / +70`；普通外出 `turn ≥ 24` 未抓娃娃时有概率触发抓娃娃；友人解锁后可出行 5 次；生病时可治病清除生病与不擅长训练。

## 5. 事件、状态与继承

- **事件结构与流程**：含 `id / name / person_index / trigger / choices / player_select`；随机事件四分类默认权重（支援卡 `0.35` / 马娘 `0.25` / 掉干劲 `0.10` / 无事 `0.30`），无事件回合不触发。掉干劲（`turn ≥ 12`）优先消耗心情盾抵消干劲下降。
- **状态标识**：`切者`（PT 折算 `×1.1`，局内获得）/ `小切`（`×1.04`，局外获得，互斥）/ `爱娇`（所有正向羁绊 `+2`）/ `擅长·不擅长训练`（失败率 `∓2%`）/ `心情盾` / `幸运体质`（待接线）/ `休息心得` / `抓过娃娃` / `生病`（位集记录种类，目前简化为标记 + 解锁治病）。
- **继承**：开局属性 `蓝因子 × 7`、上限 `floor(蓝因子 × 5.33)`（估算）；局中（turn `30 / 54`）属性 `蓝因子 × 6 + round(剧本因子 × scale)`、PT `round(剧本因子[PT] × (0.5 + 0.5 × scale))`，五维与 PT 共用同一次 `scale = random(0..2)`，并同步累加五维上限 `floor(蓝因子 × 5.33)`。

## 6. 评分与育成结束

- **总分**：`score = 已学技能分(初始 510) + floor(总 PT) × PT 折算率 × 切者系数 + Σ 五维属性分(min(属性, 上限))`，其中 `总 PT = 技能点 + Hint 总级数 × Hint 折算率`；`ScoreParts` 保持三字段（7 个分量）之和逐位等于总分。
- **五维评分公式**：1200 以内每 50 点一档、1201–2801 每 20 点一档、2802 以上每 50 点一档且增量递增，按原始属性纯公式计算（不查表、无属性上限封顶，超出 `i32` 时饱和至 `i32::MAX`）。
- **育成结束**：所有结束事件统一在 turn `77` 结束后（`AfterTrain` 或更晚）判定。

## 7. 引擎数据约定、模拟简化与未接线项

### 7.1 数据编码约定（`gamedata/`）

1. **卡 ID / 突破等级**：`idrank = 卡 ID × 10 + 突破等级`（`0..4`）；协议帧与合成帧的卡组字段一律按该合并值写出，解析侧拆开取卡面与突破等级。
2. **卡类型码**：`0` 速 / `1` 耐 / `2` 力 / `3` 根 / `4` 智 / `5` 友人 / `6` 团队。
3. **训练基础值表**：`[训练位][等级] → [速, 耐, 力, 根, 智, PT, 体力]` 共 7 列。
4. **五维属性游戏侧 ID**（与卡类型码不同）：速 `101` / 力 `102` / 根 `103` / 耐 `105` / 智 `106`。
5. **事件 ID 分段**：`8001–8003` 支援卡连续事件、`4012/4013` 局中继承、`5007` 通用切者、`80905xxxx` 友人事件；线上真实事件 ID 形如 `8 + 归属(5位) + 序号(3位)`。
6. **事件额外效果（`extra_status`）**：`random`（等概率不重复抽 `count` 项五维）与 `last_train`（上次训练对应五维，仅训练后事件使用，引擎不自动清空 `last_train`）。

### 7.2 模拟简化与未接线通用项

- **模拟简化**：比赛默认全胜；URA `73 / 75 / 77` 走独立 `race_ura_*` 系统事件（缺失回退 `race_career`），其余生涯赛奖励平均化为 `race_career`；训练失败连掷两次判定大失败并置 `Ill::BAD_TRAINER`；除 `BAD_TRAINER` 已完整接线外，其余常规生病仅作标记并解锁治病；事件成功/失败两支帧还原暂用通用默认成功率（待真实剧本校准）。
- **未接线通用项**：`absent_rate_drop`（出场率提升暂无数据源）、`幸运体质` 免疫接线、通用事件 `add_flags / remove_flags` 自动应用、`group_buff_turn` 由使用团队卡的剧本自行维护。
- **通用接缝扩展点**：支援卡事件率（`constants.json` `event_probs.card_event = 0.35`，可用卡人头均匀抽取）目前为全局固定口径，待按需开放剧本覆写 seam。
