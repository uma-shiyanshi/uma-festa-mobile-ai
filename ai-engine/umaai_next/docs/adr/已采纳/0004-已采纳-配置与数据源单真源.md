# ADR-0004: 配置与数据源单真源

- **状态**：已采纳
- **日期**：2026-10-17
- **关联**：`crates/umaai-core/src/data/`、`crates/umaai/src/config/mod.rs`、`gamedata/`

## 背景（Context）

旧实现中同一配置参数在 Rust `serde(default)` 与配置文件中各存一份默认值，导致实测口径分歧；同时数据加载最初假设数据根必在本地磁盘，难以适配 Web/Android 内嵌或内存资产宿主，且覆盖层配置若放在数据根内会在数据更新时被覆盖。

## 决策（Decision）

1. **配置单真源与双层覆盖**：默认值**只存在于数据根 `ai_config.toml`**（字段齐全），Rust 侧不提供同名字段缺省；宿主目录同名 `ai_config.toml` 作为覆盖层（字段全可选，存在才合并，段缺失整段沿用）；未知键一律严格报错。
2. **`DataSource` 抽象与多源加载**：静态表经 `DataSource`（`table<T: DeserializeOwned>(file)` + `key()`）载入，内置 `DirSource`（磁盘目录）与 `MemorySource`（JSON 值 / JSON 文本），全局 `Data::init_from` 按来源标识幂等校验，不做进程内热更新与多源叠加器。
3. **配置不进 `DataSource`**：静态表走 `DataSource`，TOML 配置走 `Config::load_with_overlay_file` 或非路径文本入口 `Config::parse`，各管各的。

## 影响（Consequences）

- **收益**：消除了代码与配置默认值双真源分歧，数据目录整包升级不冲掉宿主覆盖配置，且支持无磁盘宿主直接内嵌资产。
- **约束**：新增配置项必须同步补齐数据根默认层 `ai_config.toml`；拼写错误会触发严格报错而非静默回退。
