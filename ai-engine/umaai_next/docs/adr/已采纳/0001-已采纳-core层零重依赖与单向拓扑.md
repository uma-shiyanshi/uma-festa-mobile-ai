# ADR-0001: core 层零重依赖与单向拓扑

- **状态**：已采纳
- **日期**：2026-10-15
- **关联**：`crates/umaai-core`、`crates/umasim`、`crates/umaai`、`crates/umaai-cli`、`crates/umaai-tools`、`crates/umaai-update`、`ARCHITECTURE.md`

## 背景（Context）

引擎需要同时服务桌面 CLI、离线工具以及 Web（WASM）/ Android（NDK）等无终端、受限环境宿主。若核心层混入终端呈现、文件监听或并行计算重依赖，会导致跨平台编译受阻、下游宿主被迫引入无关依赖，且领域逻辑与基础原语边界模糊。

## 决策（Decision）

1. **单向依赖拓扑**：`umaai-cli` → `umaai` → `umasim` → `umaai-core`；`umaai-tools` 与 `umaai-tests` 仅依赖上游而不被发布；`umaai-update` 保持零引擎依赖，不在引擎依赖链上。
2. **`umaai-core` 准入门槛**：仅收录**跨算法复用且与具体游戏、具体算法无关**的纯原语（「零依赖」只是必要条件，不构成准入理由），包括纯 schema/DTO、`Data`/`DataSource` 加载与校验、统计原语、CRN 种子表、RNG 三流、统一错误与 `diag!` 宏。
3. **行为与契约归 `umasim`**：带行为的领域类型（`Uma`、`BaseGame`、`BasicGame`）、全部契约 trait（`Game`、`Trainer`、`FlatSearchGame`）与搜索算法归 `umasim`；终端呈现（着色/表格/交互）严格隔离在 `umaai-cli`。

## 影响（Consequences）

- **收益**：`umaai-core` 与引擎稳定面保持轻量跨平台，下游 Web/Android 宿主无需承担终端或桌面 IO 依赖。
- **约束**：新增工具或原语进入 `umaai-core` 前必须满足游戏/算法无关判据；类型在 `core`、trait 在 `umasim` 时，`impl` 一律落在 `umasim` 侧，严禁反向依赖。
