# umaai-next 领域与引擎术语表

本术语表只定义引擎仓上下文中的标准领域概念、核心契约名与禁用别名，不含数值公式与实现细节（分流至 [docs/mechanism.md](docs/mechanism.md) 与 [docs/adr/](docs/adr/)；历史变更回顾见 [docs/changelog.md](docs/changelog.md)）。

## 引擎与架构

**核心层（`umaai-core`）**：
零重依赖基础层，承载纯 schema/DTO、`DataSource` 加载、RNG 三流原语、CRN、统计原语与诊断宏。

**计算层（`umasim`）**：
纯计算层，承载 `Game` / `Person` / `ActionEnum` / `Trainer` 契约、`BaseGame` 状态底座与 `FlatSearch` 搜索框架（无终端依赖）。

**引擎层（`umaai`）**：
运行编排层，承载 `Runner`、`Session`、`Config` 覆盖层、`Frontend` 回调契约与帧协议解析。

**剧本仓（scenario repo）**：
以独立 workspace 形态引用引擎稳定面的具体剧本仓库（不进引擎仓、不 fork 引擎）。

**`StageId`（阶段位置标识）**：
剧本显式赋号的阶段数字，引擎只透传不做分支；改号会导致旧种子与基线失效。

**`View DTO`（剧本资源快照）**：
剧本自持的纯值快照结构体（单一取数口、只放引擎不知道的字段、`#[non_exhaustive]`、不进契约 trait）。

**无状态随机流（`SplitmixRng`）**：
值语义确定性随机数流，克隆即独立分支，支撑局部流派生与 `CRN`（共同随机数）。

**三规则流 + 独立决策流**：
引擎与剧本共用的随机流隔离模型：局面流与事件流（`BaseGame` 持有、按回合派生）、策略流（具体 `Game` 自持），以及独立决策流（只喂 `Trainer`）。

**`fork_for_rollout`**：
`FlatSearchGame` 创建模拟分支的唯一入口（克隆局面 + 注入 rollout 种子 + 重置自持流）。

**回合帧（`ThisTurn`）**：
在线模式下客户端在回合决策点输出的当前局面与事件快照帧。

**终局帧（`FinalScoreFrame`）**：
育成结束、点技能前输出的真机终局属性与复盘动作序列帧（仅用于终局核对与归档，不进决策链路）。

**切局键（`epoch_key`）**：
标识单次育成对局的身份键，供在线会话与前端识别新开局及匹配同局终局帧。

## 育成流程与状态

**回合（`turn`）**：
0 基计数（标准育成 `0..=77`，游戏内显示为 1 基）。

**训练（`Train`）**：
包含速度、耐力、力量、根性、智力五个常规训练位（`five_status` 序号 `0..=4`）。

**夏合宿**：
固定夏季集训窗口（turn `36–39` 与 `60–63`），强化训练与休息且禁止常规/友人外出。

**休息（`Sleep`） / 外出（`NormalOuting` / `FriendOuting`）**：
消耗回合恢复体力或调整干劲的基础动作；友人解锁后可执行 `FriendOuting`。

**干劲（`motivation`）**：
1–5 档心情状态（3 为普通）；对应支援卡加成词条 `ganjing`（干劲加成）。
_避免使用_：心情档位混称（代码与公式统一用干劲）

**切者 / 小切（`qiezhe` / `xiaoqie`）**：
技能点数消耗减免状态（切者局内获得、小切局外获得，两者互斥），终局评分按对应折算系数放大技能点得分。

**爱娇（`aijiao`）**：
使所有正向羁绊获取额外提升的正面状态。

**心情盾（`positive_thinking_count`）**：
在干劲下降时自动消耗一层以抵消该次下降的保护状态。
_避免使用_：ポジティブ思考、メンタルガード、正向思考

**生病 / 异常状态（`ill` 位集）**：
育成期间的负面状态位集（太り気味/变胖、肌あれ/皮肤差、片頭痛/偏头痛、なまけ癖/摸鱼、夜ふかし気味/熬夜、練習ベタ/不擅长训练）。
_避免使用_：バステ

## 训练、人物与比赛

**训练等级（`train_level`）**：
五项常规训练各自独立的设施等级（随训练成功次数升级，上限取基础值表实际行数）。

**牵绊 / 羁绊（`friendship`）**：
支援卡与育成马娘之间的好感度（达 80 触发友情训练/彩圈 `is_shining_at`）。

**擅长率 / 得意率（`deyilv`）**：
影响支援卡出现在对应擅长训练位的概率权重。

**友情加成（`youqing`） / 训练效果（`xunlian`）**：
支援卡训练增益词条；`youqing` 仅在彩圈时生效。

**启发率 / 灵感（`hint` / `total_hints`）**：
训练中触发技能提示的事件与累计获得的折扣等级。
_避免使用_：提示

**不在率（`absent_weight`）**：
人物在当回合不出现在任何训练位的判定权重。

**固有目标赛事 / 自选比赛（`career_races` / `free_races`）**：
马娘生涯日程规定的必跑比赛，以及指定回合区间内须满足场次与等级门槛的自由比赛；已参赛回合位段记为 `win_races`。
_避免使用_：育成目標

**比赛加成（`race_bonus`）**：
赛后事件与奖励对五维及技能点的乘算加成。
_避免使用_：レスボ

**URA 决赛**：
育成末期固定赛程（turn `72–77`，含 3 次训练与 3 次固定比赛）。

## 评分与缩写

**评分（`score` / `ScoreParts`）**：
终局评价点总分，拆分为五维属性分、技能分与技能点折算分（`total_pt`）。
_避免使用_：評価点

**`CRN` / `MCTS` / `UCB` / `NN`**：
共同随机数 / 蒙特卡洛树搜索 / 上置信界 / 神经网络。
