# 数据表字典与资产溯源（<剧本名>）

> 本文件记录游戏数据表结构与仓内剧本资产（`data/scenario.json`，改名后为 `data/<剧本>.json`）的溯源映射。
> 填完后：机制结论落 [`mechanism.md`](mechanism.md)，术语落 [`../GLOSSARY.md`](../GLOSSARY.md)，口径裁定落 [`changelog.md`](changelog.md)，数值占位落 [`stubs.md`](stubs.md)。
> 规则：**机制未确认 = 阻塞**；**数值待确认 = 可不阻塞**（用占位并登记）。来源必须标可信度。

## 1. 情报来源优先级

- 官方公告 / 游戏内规则 / 剧本数据表 / 真机回合帧与终局帧 > 日文调查备忘 > 社区攻略 / 口述。
- 同一事实多处冲突时以高可信度来源为准，分歧记入 [`changelog.md`](changelog.md)。
- 文件类情报（帧 / 截图 / 表）只记仓内相对路径或来源标识，不写本机绝对路径。

## 2. 引擎静态表边界（`gamedata/`）

> 以下六张静态表由引擎 `DataSource` 统一载入，初始化剧本仓时直接从引擎 `gamedata/` 拷入 `data/`；剧本专属数值与机制参数不塞入这些表，而放在 `data/scenario.json`（或 `<剧本>.json`）。

| 文件 | 承载内容与边界 | 备注 |
|---|---|---|
| `cardDB.json` | 支援卡静态表：卡种、初始/固有效果、加成参数、支援卡事件 ID | 卡池与卡面数值真值来源 |
| `umaDB.json` | 马娘角色静态表：初期属性、成长率、适性、生涯赛（`races`）与自选赛（`freeRaces`） | 角色与赛程真值来源 |
| `events.json` | 通用、角色与支援卡事件表：事件分支、选项效果、触发权重 | 事件文本与效果数值载体 |
| `text_data_dict.json` | 本地化文本字典：卡名、角色名、事件名与界面文案 ID 映射 | 只读文本查表，不参与数值结算 |
| `constants.json` | 引擎通用常量：基础回合数、训练/比赛/事件概率等全局基座常量 | 剧本特化常量勿覆盖此表 |
| `manifest.json` | 静态数据根的 schema 版本与必需文件清单 | 引擎载入静态表的唯一校验入口（不含 `ai_config.toml`） |
